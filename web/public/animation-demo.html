Use Fit to full browser width or Full screen to test a playhead moving across the widest possible bar. Press Esc to exit fullscreen. Compare movement methods at the same width, BPM and thickness. A thicker line can disguise edge flicker; it cannot repair missed frames. Metrics measure main-thread animation callbacks, not compositor output. The trace records every frame (timestamp, interval, position) while running: window.demoTrace(), window.demoTraceCsv() and the Export trace CSV button; on iPadOS copy it from the console with copy(demoTraceCsv()). URL parameters preconfigure this page, e.g. ?bpm=30&method=transform&fit=1&thickness=3.
